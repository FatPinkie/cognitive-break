Privacy Policy

Cognitive Break Pipeline · last updated 9 October 2026

Cognitive Break Pipeline is an internal, single-user tool used by the owner of the Cognitive Break YouTube channel to upload and schedule the channel's own videos and to read the channel's own analytics. It is not offered to the public and has no users other than the channel owner.

What data the tool accesses

Through the YouTube Data API and YouTube Analytics API, with the channel owner's authorisation, the tool can upload videos to the channel, set their titles, descriptions and schedule, post comments and manage playlists on the channel, and read the channel's view and audience statistics.

How the data is used

The data is used only to publish the channel's own videos and to review how they perform. Nothing is shared with, sold to, or transferred to any third party.

Where the data is stored

Authorisation tokens and downloaded statistics are stored only on the channel owner's own computer. No server, database or hosted service belonging to the tool exists.

Google user data

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google account permissions page.

Contact

Questions about this policy can be sent through the Cognitive Break YouTube channel's About page.
